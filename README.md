# Tube OTTMTY

Dos apps de video: una para celular y otra para TV. Descárgalas en [Lanzamientos](../../releases/latest):

- **YouTube-M.apk** — celular (`com.ottmty.tubemobile`)
- **YoTuve-Tv.apk** — TV (`com.ottmty.tubetv`)

Basado en [SmartTube](https://github.com/yuliskov/SmartTube) de @yuliskov y en [NewTube](https://github.com/aleixrodriala/newtube) de @aleixrodriala, bajo licencia GPL-3.0 (ver `LICENSE`).
